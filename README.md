# Human 3.0 人生战略控制台

基于 Dan Koe **Human 3.0** 模型的人生战略对话系统。顾问每次只问一个最重要的问题，
左侧的四象限评估、战略路线与成长档案随对话自动更新。

---

## 快速开始

```bash
python server.py
```

然后打开 **http://127.0.0.1:8787**，点右上角齿轮 → 填入 API Key → 保存 → 点「测试连接」。

Windows 也可以直接双击 `启动服务.bat`。

> 只依赖 Python 3.9+ 标准库，**不需要安装任何第三方包**。

命令行参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--host` | `127.0.0.1` | 改成 `0.0.0.0` 可供局域网访问 |
| `--port` | `8787` | 端口 |

## 架构：为什么不会再有「评估失败」的打扰

```
浏览器 ──POST /api/chat──► server.py ──┬─► 第一阶段：对话模型（流式，只要自然语言）
                                       │        └─ 逐字 SSE 推回浏览器
                                       │
                                       └─► 第二阶段：评估模型（独立小请求，只要 JSON）
                                                └─ 解析成功 → 更新雷达图/分数/路线/档案
                                                   解析失败 → 静默跳过，面板沿用上一次结果
```

关键设计：

1. **对话与评估彻底分离。** 评估不再绑定在对话回复里，模型不必在「好好说话」和
   「输出 JSON」之间二选一，格式错乱的概率大幅下降。
2. **评估失败零打扰。** 失败时不弹任何红色提示，只把顶栏那个状态点标灰；
   鼠标悬停才告诉你「本轮未产生新评估」。对话体验完全不受影响。
3. **三层容错。** ① 流式为空 → 自动改用普通请求；② `response_format` 被接口拒绝 →
   自动摘掉重试；③ JSON 解析失败 → 正则兜底抠分数，再不行才静默跳过。
4. **代理在服务端。** 浏览器不再直连大模型，绕开 CORS 与跨域限制，Key 只留在本机。
5. **评分有记忆。** 每轮评估都会带上「当前评分快照」，并要求单次调整不超过 0.3，
   分数会平滑演化而不是乱跳。每次评估同时写入 `history`，左侧「成长曲线」按轮次画出来。

## 功能

- **对话档案**：多会话管理（新建 / 切换 / 双击标题重命名 / 删除），全部持久化在服务端
- **四象限评估**：SVG 雷达图 + L1/L2/L3 分级 + 进度条
- **成长曲线**：四条折线按对话轮次展示四个象限的等级变化
- **战略路线建议**：每轮刷新，最多 4 条、每条 30 字以内的可执行动作
- **认知突破档案**：出现新突破时自动打时间戳归档
- **设置项**：Base URL / Key / 对话模型 / 评估模型 / 温度 / 自动分析 / JSON 模式 / 连接测试

> 「评估模型」可以单独填一个更便宜或更快的模型（例如对话用大模型、评估用小模型），
> 因为评估是每轮一次的独立小请求。

## 自测

```bash
# 终端 1：模拟大模型
python dev/mock_llm.py --port 8799 --mode good

# 终端 2：把 config.json 的 base_url 指向 http://127.0.0.1:8799/v1 后启动
python server.py

# 终端 3：跑测试
python dev/smoke_test.py                 # 主流程 25 项
python dev/degraded_test.py --expect bad_analysis   # 评估失败 → 静默降级
python dev/degraded_test.py --expect empty          # 流为空 → 自动兜底
python dev/degraded_test.py --expect refuse         # 鉴权失败 → 清晰报错
```

`mock_llm.py` 的四种模式：`good` / `bad_analysis` / `empty` / `refuse`。

## 备注

- `config.json` 里的 API Key 只保存在本机，不会上传到任何第三方；
  `GET /api/config` 只回传掩码，不回传明文。
- 换用其它兼容 OpenAI 协议的模型（如各类中转、Moonshot、通义、本地 Ollama）只需改
  Base URL 与模型名；若接口不支持 `response_format`，在设置里关掉「JSON 模式」即可。
